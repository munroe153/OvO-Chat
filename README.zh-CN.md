# OvO Chat

> 在 Obsidian 里和 DeepSeek 聊天，聊着聊着就聊出了一棵问答树。

OvO Chat 是一个 Obsidian 第三方插件。它把每段对话保存成「问 → 答」的树，而不是一条只能往下滚的直线：同一个问题可以有好几个答案，任何一个答案都能接着追问，改掉已发送的问题也不会把原来的分支弄丢。

插件的数据都放在自己的目录里，不会往你的笔记库里乱塞文件。桌面端、iOS、Android 都能用。

---

## 它都能干什么

先来个一目了然版：

- **分支对话**：一问多答、任意节点续聊、改问题保留原问句，聊错方向也不用重开一局。
- **对话树侧边栏**：把整个会话的分支结构摊开看，点哪个节点就跳到哪。
- **历史记录**：搜索、打标签、按时间筛选、排序、重命名、批量删除，全都有。
- **联网搜索**：直接调用 DeepSeek 官方的服务端联网工具，回答下面会列出参考来源。
- **读你的笔记**：模型可以检索笔记、读笔记、列笔记、读当前打开的那篇——全是只读，不会改你的库。
- **画图表**：支持 Charts 图表和 Mermaid 图，流程图、时序图、甘特图、思维导图都能画。
- **图片附件**：上传、粘贴、拖拽都行，也能一键把当前笔记塞进对话。
- **临时对话**：不落盘的悄悄话模式，关掉就消失。
- **专注时间**：开一段「不许聊天」的时间，专治手痒。
- **个性化**：调语气、亲切度、热情度、emoji 和排版风格。
- **语法增强**：MathJax 公式、mhchem 化学式、Chem 分子结构，还有表格和高亮的渲染修正。
- **手机也能用**：没依赖 Node.js 或 Electron，`isDesktopOnly` 是 `false`。

## 安装

### 前置条件

- Obsidian **1.11.4** 或更高版本（这个版本才有插件需要的密钥库 API）。

### 从社区插件市场装（如果已经上架）

1. 打开 **设置 → 第三方插件 → 浏览**。
2. 搜 **OvO Chat**，安装并启用。

### 手动安装

1. 从发布页下载 `main.js`、`manifest.json`、`styles.css` 三个文件。
2. 在你的库里创建目录 `<库>/.obsidian/plugins/ovo-chat/`（没有就建）。
3. 把三个文件丢进去。
4. 重载 Obsidian，在 **设置 → 第三方插件** 里启用 **OvO Chat**。

> 别改 `main.js` 和 `manifest.json` 的文件名，Obsidian 是按固定名字加载的。

---

## 第一次用：先把钥匙配好

OvO Chat 走的是 DeepSeek 官方 API，所以得先去 [platform.deepseek.com](https://platform.deepseek.com) 建一个 API Key。

1. 打开 **设置 → OvO Chat → 密钥**。
2. 在 **API 密钥** 里选一个已有的密钥，或者新建一个（比如叫 `deepseek-api-key`），然后把 Key 值粘进去。
3. 点 **测试连接**。成功了会告诉你当前有哪些模型可用，顺便把模型列表刷新一遍。

有几个小地方要注意：

- 插件只存密钥的**名字**，Key 的值由 Obsidian 内置密钥库保管，不会写进插件的 `data.json`。
- 密钥库是跟当前库绑定的，**不随库同步**。换电脑、换手机，都要各自配一次。
- 没配密钥也能打开界面，但发消息时会提示你去设置里配。

## 打开聊天窗口

三种方式随你挑：

- 点左侧边栏的 **消息气泡图标**。
- 命令面板搜 **打开对话窗口**。
- 命令面板搜 **新建对话**，直接开一段新的。

另外还有几个命令：

| 命令 | 干什么的 |
| --- | --- |
| 打开对话窗口 | 打开或切到聊天标签页 |
| 新建对话 | 开一段新对话 |
| 打开对话树（侧边栏） | 在右侧边栏打开问答树 |
| 打开历史记录 | 打开完整历史记录页 |
| 专注时间 | 开启一段专注时间 |

### 界面长这样

聊天窗口从上到下大致是：

```
┌ 顶栏：标题 / 定位 / 临时对话 / 历史 / 新建
├ 输入区：工具栏 + 附件预览 + 输入框 + 发送按钮
├ 消息流：问答 / 思考过程 / 来源 / 工具调用
└ 状态栏：模型 + 上下文 token 估算
```

输入框放在上面是为了照顾 iPad：软键盘弹出来时不容易把它挡住。

### 发消息

- 默认 **Enter 发送、Shift+Enter 换行**；也可以去 **设置 → 高级 → 发送键方案** 改成反过来。
- **Ctrl/Cmd+Enter 永远发送**，记不住设置就用这个。
- 中文输入法选字的时候按 Enter 不会误发。
- 发送按钮在生成过程中会变成 **停止** 按钮，点一下就能掐断。已经生成的部分会保留，末尾标一句「已停止生成」。

## 核心玩法：把对话聊成一棵树

这是 OvO Chat 最不一样的地方，值得单独说说。

普通聊天是一问一答排成一条线。OvO Chat 里，每个问题都是一个节点，节点下面可以挂：

- **多个答案**：同一个问题重新生成几次，就存几个答案，随时左右切换。
- **多个子问题**：从某个答案继续追问，就长出一个新的子分支。
- **改写过的问题**：编辑已发送的问题，会生成一个同级的新分支，原来那条分支原封不动留着。

### 重新生成，多攒几个答案

在答案下面点 **刷新图标**，就会基于同一个问题重新生成一个答案。旧答案不会丢，答案下方会出现 `‹ 1/2 ›` 这样的切换条，点箭头就能来回翻。

### 编辑问句，保留原分支

把鼠标移到你自己发的那条消息上（手机上直接点气泡附近的铅笔按钮），点 **铅笔**：

- 气泡会变成输入框。
- 改完点 **保存并生成**（桌面端也可以直接按 Enter，Esc 取消）。
- 新问题会作为原问题的**同级分支**挂上去，原来的问题和它的所有答案、子分支都完整保留。
- 保存后会立刻用新问题重新生成答案。

### 从任意节点接着聊

打开右侧边栏的 **OvO** 对话树，你会看到整段会话的分支结构：

- 亮起来的那条是当前激活路径。
- 每个节点显示问题摘要；答案不止一个的节点会带个 `×N` 徽标。
- 点任意节点，聊天窗口就会跳到那个问题，并把当前路径截断到那里。
- 这时候再发消息，就是从该节点继续往下长新分支。

> 小提示：这个「跳到哪个节点」的游标只活在当前会话里。重开插件或重新打开会话，会回到整条激活路径的末端。

### 定位到最后一个问题

顶栏的 **锚点图标** 可以一键滚回当前路径的最后一个问句，不改变任何分支状态。

## 历史记录

顶栏的 **历史图标** 会弹出最近 10 条对话，底下还有「更多历史记录」和「删除当前对话」。

想看全部对话，就打开完整的 **历史记录** 标签页：

- **搜索**：按标题或标签搜，大小写不敏感。
- **标签筛选**：点标签 chips，多选时要求会话**同时包含**所有选中的标签。
- **时间筛选**：按创建时间或修改时间，看今天 / 近 7 天 / 近 30 天 / 全部。
- **排序**：修改时间或创建时间，新的在前或旧的在前。
- **管理**：每行可以编辑标签、重命名、删除；还能勾选多个批量删除。

标签用英文逗号或中文逗号分隔都行，比如 `工作, 读书笔记`，留空就是清空标签。重命名和改标签**不会**刷新「修改时间」，所以不会把历史排序搅乱。

删除对话是不可撤销的，会话文件和附件目录会一起删掉。

## 联网搜索

点输入区工具栏的 **联网** 按钮，图标亮起来就代表开了。

- 用的不是插件自己爬网页，而是 DeepSeek 官方的服务端 `web_search` 工具。
- 搜索过程中会显示「正在联网搜索：关键词…」。
- 回答下面会出现 **来源（N）**，默认折叠，点开就是链接列表。
- 每条回答的元信息会标 **🌐 已联网检索** 或 **⚠️ 未触发联网检索**，方便判断模型到底有没有真的搜。
- 插件还会额外叮嘱模型：遇到可能过时的信息先搜再答，别凭记忆编。

联网开关是**当前对话窗口**的运行时状态；打开对话窗口时的初始值，可以在 **设置 → 工具** 里改。

## 让模型读你的笔记

点输入区工具栏的 **工具** 按钮，模型就能调用四个内置的只读工具：

| 工具 | 作用 |
| --- | --- |
| `search_notes` | 全库检索 Markdown 笔记，返回路径、行号和片段；支持按目录、条数限制 |
| `read_note` | 按库内路径读一篇笔记全文，太长会截断 |
| `list_notes` | 列出库里的笔记路径，可以只看某个目录 |
| `get_active_note` | 读当前正在看的那篇笔记 |

几个实际使用中的点：

- 这些工具**全是只读**的，不会修改、创建或删除任何笔记。
- 模型一次回复里最多可以连续调用 8 轮工具，防止它绕不出来。
- 每次调用都会在消息里显示一行轨迹，点开「参数 / 结果」能看到具体调了什么、返回了什么。
- 单次读取的字符上限可以在 **设置 → 工具 → 读取范围** 里调，默认 20000，范围 1000–200000。
- 工具调用模式也是当前对话窗口的运行时状态；打开对话窗口时默认开不开，同样在 **设置 → 工具** 里设置。

> 工具和联网可以同时开。联网由 DeepSeek 服务端执行，内置工具由插件在本地执行，两者互不打架。

## 附件和当前笔记

### 图片附件

三种方式加图片：

- 点工具栏的 **附件**（回形针）选文件。
- 直接把图片**粘贴**进输入框。
- 把图片**拖进**输入区域。

限制和细节：

- 支持 PNG / JPG / GIF / WebP，单张最大 **16MB**。
- 一次发送的附件总大小别超过大约 **40MB**，不然会被拦下来。
- 发送前可以预览、可以逐个移除。
- 图片会存到插件目录的 `attachments/<会话 id>/` 里，会话文件本身只留引用，不把 base64 塞得到处都是。

### 把当前笔记塞进去

点工具栏的 **当前笔记**，当前打开的那篇笔记会作为文本附件附在这一条消息里。适合「帮我总结这篇」「根据这篇改个大纲」这种场景。

> 上传附件只支持图片；当前笔记是文本附件的唯一入口。

## 绘图模式

点输入区工具栏的 **绘图** 按钮，插件会往系统提示词里注入图表语法说明。之后你直接说「帮我画个季度销售柱状图」之类的话就行。

### 两种图

**Charts 图表**（`chart` 代码块）：

- 需要先在库里安装并启用 **Charts**（`obsidian-charts`）插件，否则代码块不会渲染成图。
- 支持柱状图 / 条形图、折线图 / 面积图、饼图、环形图、雷达图、极坐标面积图。

**Mermaid 图表**（`mermaid` 代码块）：

- Obsidian 原生渲染，不用装额外插件。
- 支持流程图、时序图、甘特图、时间线、思维导图、看板。

### 只画你想要的类型

去 **设置 → 提示词 → Charts 图表 / Mermaid 图表**，把不需要的类型取消勾选。绘图模式只会注入勾选类型的提示词，省 token 也更不容易跑偏。默认全选。

### Mermaid 画坏了怎么办

模型写 Mermaid 语法偶尔会犯小错（最常见的是边标签少半个引号）。插件会：

1. 先尝试窄范围修复，比如补全引号。
2. 用 Obsidian 自带的 Mermaid 实例做一次语法预校验。
3. 实在修不好，就降级成「⚠️ 解析失败 + 原始源码」，而不是甩你一脸解析报错。
4. 流式生成过程中，半截的 Mermaid 先按代码块展示，等答案完整了再正式渲染。

所有这些处理都只影响**渲染出来的样子**，不会改会话里存的原文。

## 临时对话（ghost 模式）

顶栏那个 **幽灵图标** 就是临时对话。

打开之后：

- 对话只存在内存里，**不写磁盘**，附件也不保存。
- 不注入个性化提示词，也不注入语法增强提示词（当日日期还是会告诉模型）。
- 顶栏标题会变成「临时对话」，发第一条消息后标题前面会加「临时 · 」。
- 点幽灵图标退出、切到历史对话、或者新建对话，临时记录都会**静默丢弃**。
- 退出临时对话时，会自动回到你进入之前的那段对话。

适合问点私密的、一次性的、不想在历史记录里留痕的问题。

---

## 专注时间

命令面板搜 **专注时间**：

1. 输入时长。纯数字按分钟算，也支持 `25m`、`1h`、`1小时30分钟` 这种写法，范围 1 分钟到 24 小时。
2. 看一眼结束时间，确认。
3. 开始之后，**发送消息、重新生成、保存问句编辑**都会被拦住，并提示还剩多少分钟。

规则很简单也很硬：

- 翻历史、看旧对话不受限制。
- **不能提前结束**。到点自动解除。
- 结束时间戳存在插件设置里，重载 Obsidian 也不会重置。
- 专注期间再执行一次命令，只会告诉你还剩多久。

## 个性化：让回答更像你要的样子

对话输入区工具栏的 **个性化** 按钮是总开关。打开后，按 **设置 → 提示词 → 个性化** 里选的档位往系统提示词里注入风格说明。

能调的东西：

- **基本风格和语调**：默认、专业可靠、亲和友善、直言不讳、天马行空、高效务实、吐槽达人。
- **亲切程度**：增强 / 默认 / 减弱。
- **热情程度**：增强 / 默认 / 减弱。
- **表情符号**：增强 / 默认 / 减弱。
- **布局和视觉元素**：默认 / 简洁。

选「默认」的维度不会注入任何提示词。总开关关掉之后，所有档位都保留，但一个都不注入。临时对话不注入个性化提示词。

> 这些提示词只约束语气和排版，不会让模型瞎编事实。

## 语法增强

### 数学和化学

去 **设置 → 提示词** 打开对应开关：

- **MathJax**：让模型用 `$…$` 和 `$$…$$` 写公式，Obsidian 原生渲染。
- **mhchem**：让模型用 `\ce{}` 写化学式，Obsidian 内置支持。
- **Chem 插件**：让模型用 `smiles` 代码块输出分子结构，一行一条。这个需要额外安装 **Chem**（`chem`）插件；没装的话设置页会提醒你。

### 渲染前修正

**设置 → 高级 → Obsidian 语法修正** 里有两个开关，默认都开着：

- **表格前后留空**：紧贴正文的表格会自动补空行，渲染出来不会跟上下文黏在一起。
- **==高亮== 归一化**：把全角 `＝＝`、三重等号之类统一成 `==`，顺便去掉标记内侧多余的空格。

这两个修正只作用于**渲染副本**，不会改聊天记录里保存的原文。代码块、行内代码、公式里的内容也不会被误伤。

## 设置页速查

| 分页 | 里面有什么 |
| --- | --- |
| **密钥** | 选择 / 新建 DeepSeek API 密钥，测试连接 |
| **界面** | 思考内容和搜索来源默认折叠；工具栏按键的显示与排序 |
| **调参** | 默认模型、默认思考强度、系统提示词、当日日期、temperature、top_p、max_tokens、停止序列、上下文长度和 token 预算 |
| **工具** | 新对话是否默认开联网 / 工具调用；读笔记的字符上限 |
| **提示词** | 个性化档位；MathJax / mhchem / Chem；Charts 和 Mermaid 的图表类型勾选 |
| **高级** | 表格和高亮修正；发送键方案 |

几个参数的小说明：

- **temperature**：0–2，越高越放飞。思考模式下不起作用。
- **top_p**：0–1。思考模式下官方只认 0.95–1.0。
- **max_tokens**：设为 0 表示不限制，交给服务端决定（注意钱包）。
- **上下文长度**：携带最近多少条历史消息，0 表示全部。
- **上下文 token 预算**：按估算 token 从最新往前保留，0 表示不限制。

工具栏上哪些按钮显示、谁排前面，也可以在 **设置 → 界面 → 工具栏按键** 里用开关和上下箭头调整。

## 数据放在哪，隐私怎么样

### 数据位置

全部在插件自己的目录里：

```
<库>/.obsidian/plugins/ovo-chat/
├── sessions/<会话 id>.json   # 每段对话的问答树
├── sessions.json             # 轻量索引：标题、时间、标签
└── attachments/<会话 id>/    # 图片等附件
```

不会在库的其他地方创建文件夹。

### 关于隐私

- 插件**没有遥测、没有统计**。
- 网络请求只发给 DeepSeek 官方接口：对话、模型列表、服务端联网搜索。
- 除了你主动发送的消息、以及你开启工具后模型读取的笔记内容，不会上传库里的其他东西。
- API Key 由 Obsidian 密钥库托管，插件配置里只保存密钥名。
- 接口地址是写死的官方地址，**不支持第三方中转或代理**。
- 删除对话会连同会话文件和附件目录一起删除，不可撤销。
- 没有 Markdown 全文导出 / 导入功能；想留底就单条消息点复制，或者自己另存。

## 常见问题

**Q：模型下拉框里怎么没有最新模型？**
模型列表是启动时从官方 `GET /models` 拉的，缓存 6 小时。去 **设置 → 密钥** 点一下 **测试连接** 就能强制刷新。没配密钥时会显示内置的兜底列表。

**Q：为什么手机端还要重新配密钥？**
密钥库跟当前库绑定，不随库同步。每台设备第一次用都要选一次或建一次密钥。

**Q：联网开了，但回答下面没有来源？**
看回答元信息：如果是 **⚠️ 未触发联网检索**，说明模型这轮没真的调搜索。换个问法、明确让它「搜一下最新消息」，或者重新生成试试。

**Q：图表代码出来了，但没渲染成图？**
Charts（`chart` 代码块）需要装 `obsidian-charts` 插件；SMILES 需要装 `chem` 插件。Mermaid 是 Obsidian 原生支持的。Mermaid 如果语法实在修不好，会显示成「警告 + 源码」，不会白屏。

**Q：为什么发不出消息？**
先看有没有弹「当前处于专注时间」。是的话只能等，不能提前结束。没开专注时间的话，检查一下 API 密钥配没配。

**Q：报 401 / 402 / 429 怎么办？**
插件会把常见状态码翻译成人话：401 是 Key 无效或没填，402 是余额不足，429 是请求太频繁。按提示处理就行。

**Q：能接第三方 API 中转吗？**
不能。OvO Chat 锁死了 `api.deepseek.com` 官方地址。

**Q：对话能导出成 Markdown 吗？**
没有整段导出功能。单条消息可以用气泡下方的复制按钮拿走 Markdown 原文。
